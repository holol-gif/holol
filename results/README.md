# Experimental Results

이 디렉터리에는 **실제 측정된 실험 결과만** 저장합니다.

## Planned comparison

핵심 비교는 다음 두 조건입니다.

- **Baseline:** JetCobot 실패를 JetCobot에서 직접 human correction
- **Transfer:** SO-101 corrective demonstration을 변환·전이한 뒤 부족한 부분만 JetCobot에서 추가 correction

## Main metrics

- Task Success Rate
- Human Correction Count
- Correction Duration
- Data Efficiency
- Transferability by failure type
- Robustness

현재 Cross-Robot Transfer의 정량 결과는 아직 확보되지 않았습니다.
결과가 생성되면 원시 trial 기록과 요약 그래프를 함께 추가합니다.
