# ROS 2 + MoveIt

ROS 2 / MoveIt 기반 경로계획과 perception-to-planning bridge 코드를 정리할 위치입니다.

대상:
- Planning Scene object insertion
- Random cube placement experiments
- Target pose planning
- Collision-aware motion planning
- Camera target → MoveIt planning bridge

대표적으로 `camera_to_moveit_plan.py` 같은 실제 파일을 정리해 추가할 예정입니다.
