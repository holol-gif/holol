# Source Code

이 디렉터리는 실제 연구 코드를 플랫폼/기능별로 정리하기 위한 공간입니다.

```text
src/
├── so101/      # LeRobot / SO-101 teleoperation, data collection, policy execution
├── jetcobot/   # JetCobot real-robot control and repeated execution
├── vision/     # Camera calibration, detection, homography, robot XY estimation
└── moveit/     # ROS 2 / MoveIt planning and perception-to-planning bridge
```

현재 실제 실험 코드 파일은 공개 전 개인정보·로컬 경로·장치 정보 등을 점검한 뒤 순차적으로 추가할 예정입니다.

README에 코드 이름이 언급되어 있다고 해서 해당 파일이 이미 공개되어 있다는 의미는 아닙니다.
