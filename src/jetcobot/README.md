# JetCobot

JetCobot 실제 제어 및 반복 Pick-and-Place 코드를 정리할 위치입니다.

대상:
- pymycobot communication / joint state checks
- Real robot motion execution
- Trial-state isolation
- Fresh observation handling
- Return sequence
- Safety / dry-run separation

대표적으로 README에서 언급한 `act_golden_fast_return_3runs_v5.py` 같은 실제 사용 파일을 정리해 추가할 예정입니다.
