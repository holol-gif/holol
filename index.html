Research Question

전체 연구는 “더 적은 사람 개입으로 다른 로봇까지 학습을 확장할 수 있는가?”라는 질문에서 출발합니다.

한 로봇에서 이미 얻은 corrective demonstration을 다른 형태의 로봇에 맞게 변환·재사용하면, 새 로봇에서 필요한 사람의 추가 교정 횟수를 줄일 수 있을까?

단순히 데이터를 복사하는 것이 아니라, 두 로봇의 실패 원인이 얼마나 유사한지, 어떤 교정이 로봇 구조가 달라도 전이 가능한지까지 평가하는 것이 핵심입니다.

Research Platforms

서로 다른 하드웨어 구조에서 동일한 조작 작업을 수행하고, 학습·교정 정보를 연결합니다.

SO-101 · LeRobot

사람의 시연을 수집하는 학습 플랫폼

Leader–Follower 텔레오퍼레이션과 캘리브레이션을 기반으로 Pick-and-Place 시연 데이터를 수집하고 모방학습 실험을 진행합니다.

진행 경험 있음

경로계획·비전·실기 실행 플랫폼

pymycobot 기반 실기 제어, MoveIt 시뮬레이션, 카메라 물체 인식 및 좌표 기반 집기 파이프라인을 구축하고 있습니다.

실기·시뮬레이션 진행

Research Method

시연 수집에서 실제 집기, 실패 분석, 교정 데이터 전이까지 단계적으로 연결합니다.

01. DemonstrationSO-101 Leader–Follower로 사람이 작업 시연
02. Imitation Learning카메라·관절 상태와 행동을 학습 데이터로 구성
03. Execution학습 정책 또는 좌표 기반 명령으로 작업 수행
04. Failure Analysis미스그립, 좌표 오차, 인식 실패 등의 원인 분리
05. Correction실패한 구간에 사람 교정 시연 추가
06. Cross-Robot Transfer교정 정보를 다른 로봇 표현으로 변환해 재사용

What Has Been Built

지금까지 프로젝트에서 실제로 구축하거나 시험한 핵심 기능만 추려 정리했습니다.

완료/검증 경험

SO-101 Teleoperation

Leader arm과 Follower arm을 캘리브레이션하고 사람이 팔을 움직여 시연을 수집하는 흐름을 구축했습니다.

실험 진행

Imitation Learning

Pick-and-Place 중심의 시연 데이터를 수집하고, 학습한 정책을 실제 로봇 동작으로 실행하는 실험을 진행했습니다.

동작 확인

JetCobot Control

JetCobot에서 pymycobot을 이용해 관절 상태를 읽고 실제 팔을 제어하는 환경을 확인했습니다.

시뮬레이션 진행

MoveIt Planning

MoveIt에서 큐브를 배치하고 충돌을 고려한 경로계획과 Pick-and-Place 동작을 시험했습니다.

개선 중

Vision → XY

초기 HSV 기반 검출을 거쳐, 현재는 배경 차분과 사각형 형상·실제 크기 점수를 이용해 색상에 덜 의존하는 큐브 위치 추정 파이프라인을 시험하고 있습니다.

다음 단계

Segmentation

현재 geometry 기반 검출의 강건성을 더 검증한 뒤, 필요 시 segmentation을 결합해 복잡한 배경과 다양한 물체까지 확장할 계획입니다.

Project Timeline

연구의 방향이 어떻게 실제 시스템 구축으로 이어졌는지 보여주는 진행 흐름입니다.

1. SO-101 기본 시스템 구축

Leader–Follower 연결, 텔레오퍼레이션, 캘리브레이션, 시연 데이터 수집 흐름 정리.

2. 모방학습 실행 실험

시연으로 학습한 정책을 실제 Pick-and-Place에 적용하고 반복 수행 안정성을 조정.

3. JetCobot 실기 제어

Jetson 환경에서 로봇 관절 상태와 제어 명령을 확인하고 실제 동작 파이프라인 구축.

4. MoveIt + Random Cube Scene

시뮬레이션 환경에 물체를 배치하고 목표 자세와 충돌을 고려한 경로를 계산.

5. Camera-based Grasping

초기 HSV 방식에서 발전해 배경 차분·사각형 형상·실제 30 mm 크기 점수와 픽셀→로봇 XY 변환을 결합. 다중 후보/트래킹 안정성 검증 중.
